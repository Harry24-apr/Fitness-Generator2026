🏋️ AI Fitness Analyzer – Milestone 4
🚀 Project Overview

The AI Fitness Analyzer is an intelligent fitness application developed as part of the Infosys Springboard Project (Milestone 4). This application uses Artificial Intelligence and Generative AI to provide personalized fitness plans, workout recommendations, and health insights based on user input.

The project is deployed using Hugging Face Spaces, allowing users to access it online.

🔗 Live App:
https://huggingface.co/spaces/Infosysprojectwork/AI_Fitness_Analyzer

🎯 Objectives
To develop an AI-powered fitness assistant
To generate personalized workout and diet plans
To provide health insights using user data
To integrate Generative AI for intelligent responses
To deploy a real-time working application
🧠 Key Features
Personalized Fitness Plan Generation
BMI Calculation and Health Analysis
Workout Recommendations (Weight Loss / Muscle Gain / General Fitness)
Diet Suggestions based on fitness goals
AI-based response generation
Interactive UI using Streamlit
Cloud deployment using Hugging Face
